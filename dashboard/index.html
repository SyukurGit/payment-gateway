💡 Panduan: Jika Sesi Habis, Bagaimana Cara Import ke VPS Live Hosting?

Zero-Downtime

Karena ShopeePay membatasi sesi login merchant sekitar 24 jam, server VPS Anda tidak perlu direstart. Pilih salah satu cara mudah berikut untuk memperpanjang sesi:

1
Buka Shopee Partner di Browser Anda
Login ke partner.shopee.co.id dari laptop / komputer Anda.
2
Ambil Token (B:...)
Salin string token yang diawali B: dari Cookie JWT atau cukup gunakan tombol Bookmarklet kami.
3
Klik Tombol "Import Token Baru"
Tempel token di jendela modal dashboard ini, lalu klik Simpan ke VPS. Token langsung aktif seketika tanpa perlu restart server VPS!

Pasang userscript kami di browser Chrome/Edge laptop Anda. Setiap kali Anda membuka tab Shopee Partner, script otomatis menyedot token aktif dan mengirimkannya ke server VPS Anda di latar belakang.

🧩 Pasang Script Tampermonkey

Jalankan perintah ini di PowerShell atau CMD komputer lokal Anda untuk memperbarui token VPS: 

python refresh_token.py --setup

Browser Chromium lokal akan terbuka. Silakan scan QR login di ponsel Anda. Begitu login sukses, token baru otomatis dikirimkan ke VPS dan browser menutup sendiri!

🚀 Cara Memulai Integrasi Web Toko Anda:

1
Daftarkan Web Toko
Buka tab Kelola Web Toko, masukkan nama toko dan URL webhook Anda.
2
Salin API Key
Pasang PAYMENTG_API_KEY di file .env aplikasi web toko Anda.
3
Otomatisasi Pembayaran
Web toko Anda panggil POST /api/orders. Saat bayar, webhook lunas dikirim otomatis.
💡 Tips Penggunaan PaymentG:
  • Sesi token ShopeePay aktif berhari-hari hingga berminggu-minggu selama akun tidak di-logout di device lain.
  • Setiap pesanan otomatis diberi kode unik acak (1–999) sehingga transfer pembeli terdeteksi secara presisi.
  • Uji coba checkout kapan saja tanpa transfer uang asli dengan membuka 🧪 Mode Sandbox.
