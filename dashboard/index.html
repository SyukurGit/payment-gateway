1
Daftarkan Web Toko
Buka tab Kelola Web Toko, masukkan nama toko dan URL webhook Anda.
2
Salin API Key
Pasang PAYMENTG_API_KEY di file .env aplikasi web toko Anda.

Web toko Anda panggil POST /api/orders. Saat bayar, webhook lunas dikirim otomatis.
💡 Tips Penggunaan PaymentG:
  • Sesi token ShopeePay aktif berhari-hari hingga berminggu-minggu selama akun tidak di-logout di device lain.
  • Setiap pesanan otomatis diberi kode unik acak (1–999) sehingga transfer pembeli terdeteksi secara presisi.
  • Uji coba checkout kapan saja tanpa transfer uang asli dengan membuka 🧪 Mode Sandbox.
