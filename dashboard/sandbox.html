💡 Cara Menggunakan Sandbox di Web Toko Anda:
  1. Buka tab 🔑 Kelola App Sandbox dan daftarkan web toko testing Anda.
  2. Salin API Key (ak_sbx_...) dan Webhook Secret ke file .env toko Anda.
  3. Set base URL di web toko ke https://paymentg.syukurapi.online/api/sandbox.
  4. Lakukan checkout di web toko Anda. Tagihan akan otomatis masuk ke tabel di atas.
  5. Klik tombol [💳 Bayar Sekarang] pada invoice tersebut. Pembayaran seketika lunas dan webhook otomatis terkirim ke web toko Anda!
