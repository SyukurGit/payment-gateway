ShopeePay Dynamic QRIS API

Integrasi tagihan QRIS dinamis berbasis EMVCo TLV dengan kode unik

← Kembali ke Dashboard
Mata Uang IDR (Rupiah)
Metode Alokasi Kode Unik 1 - 999
Kompatibilitas QRIS BCA, Mandiri, BRI, GoPay, OVO, ShopeePay, DANA

🔑 1. Autentikasi API Key

Kirimkan header X-API-Key pada setiap panggilan API.

Mode Live (Produksi): X-API-Key: ak_live_xxxxxx
Mode Sandbox (Testing): X-API-Key: ak_test_xxxxxx

🌐 2. Ringkasan Endpoint

Method Live Path Sandbox Path Fungsi
POST /qris/api/orders /qris/api/sandbox/orders Buat invoice QRIS dinamis
GET /qris/api/orders/:id /qris/api/sandbox/orders/:id Cek status invoice
GET /qris/api/orders/:id/qr.png /qris/api/sandbox/orders/:id/qr.png Render gambar QRIS PNG
POST - /qris/api/sandbox/orders/:id/pay 1-Klik Simulasi Lunas Sandbox

⚡ 3. Membuat Tagihan QRIS Dinamis

Membuat tagihan baru dengan kode unik otomatis yang mencegah bentrok antar pembeli.

Request cURL: 
curl -X POST https://multipay.domain.com/qris/api/orders \
  -H "Content-Type: application/json" \
  -H "X-API-Key: ak_live_xxxxxx" \
  -d '{
    "reference_id": "INV-2026-001",
    "amount": 50000,
    "expiry_minutes": 15
  }'
Response (JSON): 
{
  "success": true,
  "order": {
    "id": "ord_qris_ab12cd34",
    "channel": "qris",
    "reference_id": "INV-2026-001",
    "currency": "IDR",
    "original_amount": 50000,
    "unique_code": 142,
    "total_amount": 50142,
    "total_amount_str": "50142",
    "status": "PENDING",
    "qr_url": "https://multipay.domain.com/qris/api/orders/ord_qris_ab12cd34/qr.png",
    "remaining_seconds": 900
  }
}

🔔 4. Webhook Notifikasi Pembayaran
