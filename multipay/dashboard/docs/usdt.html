🔑 1. Autentikasi API Key

Kirimkan header X-API-Key pada setiap panggilan API.

Mode Live (Produksi): X-API-Key: ak_live_xxxxxx
Mode Sandbox (Testing): X-API-Key: ak_test_xxxxxx

🌐 2. Ringkasan Endpoint

Method Live Path Sandbox Path Fungsi
POST /usdt/api/orders /usdt/api/sandbox/orders Buat invoice USDT On-Chain
GET /usdt/api/orders/:id /usdt/api/sandbox/orders/:id Cek status invoice
GET /usdt/api/orders/:id/qr.png /usdt/api/sandbox/orders/:id/qr.png Render gambar QR Wallet
POST /usdt/api/orders/:id/check /usdt/api/sandbox/orders/:id/check Trigger scan RPC on-demand
POST - /usdt/api/sandbox/orders/:id/pay 1-Klik Simulasi Lunas Sandbox

⚡ 3. Membuat Tagihan USDT BEP-20

Request cURL: 
curl -X POST https://multipay.domain.com/usdt/api/orders \
  -H "Content-Type: application/json" \
  -H "X-API-Key: ak_live_xxxxxx" \
  -d '{
    "reference_id": "ORDER-USDT-991",
    "amount": 10.00,
    "expiry_minutes": 15
  }'
